# ASP.NET Product API

## 📌 專案介紹

使用 ASP.NET Core Web API 開發的商品管理系統。

使用 ASP.NET Core 搭配 JWT 驗證機制建構 RESTful API。
* 實作基於 JWT 的身份驗證與授權機制
* 使用 ASP.NET Identity PasswordHasher 進行安全的密碼雜湊處理
* 以 Entity Framework Core 設計 CRUD API
* 採用 DTO 模式進行資料傳輸
* 過基於 Claims 的授權機制，落實使用者層級的資料存取控制

---

## 🚀 技術

* .NET 8
* Entity Framework Core
* RESTful API

---

## ✨ 功能

* 商品 CRUD
* DTO（輸入 / 輸出分離）
* Service Layer 架構
* API 統一回應格式
